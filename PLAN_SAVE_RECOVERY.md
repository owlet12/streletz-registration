# Сохранение планов · Windows-мост 0.5.29

Автор: [owlet](https://github.com/owlet12).

Исправлена ошибка «Не удаётся удалить заменяемый файл» после «Сохранить планы».

- Запись выполняется в фоне; окно не закрывается до успешного сохранения.
- Перед заменой существующего проекта рядом создаётся резервная копия `имя.s3project.before-plans-дата-код.bak`.
- При временной блокировке выполняются до трёх попыток с короткой паузой. Повтор ограничен ошибками Windows 32, 33 и 1175, при которых исходные имена сохранены.
- Если файл остаётся занят, новый проект сохраняется рядом под именем `имя-plans-дата-код.s3project`. Мост переключается на него: новое имя отображается над таблицей и в строке состояния. Исходный файл остаётся прежним. APK получает проект из новой копии обычной командой «Загрузить проект из Windows».
- Если новая копия также не записывается, редактор остаётся открытым. Сообщение можно выделить и скопировать. Нажмите «Сохранить планы» повторно либо **«Сохранить как…»** и выберите новое имя в доступной папке. Существующий файл этим действием не перезаписывается.

При ошибке после подготовки записи полный новый проект сохраняется рядом в `.pending`, а прежний — в `.bak`. Пути указаны в сообщении. Для ручного восстановления скопируйте нужный файл под новым именем с расширением `.s3project` и откройте копию в мосте. Не удаляйте исходник до проверки восстановленной копии.

Исходный файл не удаляется принудительно и не перезаписывается по частям. Блокировка файла другой программой не снимается. Неоднозначные ошибки замены 1176/1177 не повторяются автоматически: подготовленный файл и резервная копия сохраняются для восстановления. Ошибки прав доступа показываются в редакторе; можно выбрать другую папку.

Сохранение проверяет текущий проект и отсутствие изменений его планов после открытия редактора. Более свежие данные регистрации остаются в проекте; при активной регистрации сохранение блокируется. Неудачная попытка не публикует новые планы для APK. Повтор использует актуальную ревизию проекта.

## Обновление

Закройте старый мост штатно, распакуйте комплект 0.5.29 и выполните `Install-Update.cmd` либо запустите `Start-Bridge.cmd` из нового комплекта. Модуль Master 1.0.9.0 и APK 0.5.28 не менялись. Настройки связи, BFX и оборудование не затрагиваются.

Если редактор 0.5.28 уже закрылся после ошибки, изменения, которые не успели попасть в файл, автоматически не восстанавливаются этим обновлением. Новая версия сохраняет редактор открытым при сбое.

## Проверки

Автоматические проверки используют только временные вымышленные проекты: обычное сохранение и резервная копия, однократная ошибка 1175, постоянная 1175, реальный запрет удаления открытого файла Windows, ошибки 5/1176/1177, внешнее изменение между попытками, запрет перезаписи занятого имени копии. Проверяется сохранность исходника и подготовленного проекта.

В собственном тестовом окне проверяются ошибка сохранения без закрытия и потери отметок, отмена «Сохранить как…», запрет закрытия во время записи и закрытие только после успешного ответа. Рабочий файл пользователя не изменяется тестами. Блокировка конкретной программы синхронизации не воспроизводится и не обходится.
