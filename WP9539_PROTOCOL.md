# WP9539: основание профиля и проверка

Автор реализации: [owlet](https://github.com/owlet12).

Профиль `wp9539` добавлен в 0.5.24. Общая передача VSON использует
существующую адаптацию MIT-драйвера [amahlaka/WP9529](https://github.com/amahlaka/WP9529/tree/5096f206ac20103089a512204425ccccdc9c802e).
Автор upstream — Arttu Mahlakaarto; его аппаратная проверка относится к WP9529/V50.

## Источник сведений о WP9539

Предоставленный пользователем APK: пакет `com.vson.ilabel`, версия 3.8,
versionCode 136, SHA-256
`0e4f96d0115ee8cce1520b66929b1d6fe61f2d2c44af89a6408adfdeed07bc40`.
Выполнен статический анализ, без установки и запуска APK. Файл получен
пользователем через APKPure; принадлежность подписи производителю отдельно
не удостоверялась. Сам APK, декомпилированные исходники, изображения,
ресурсы и идентификаторы физического устройства в комплект не включены.
Ниже приведены факты о взаимодействии, реализация написана независимо.

| Наблюдение | Место в iLabel 3.8 |
|---|---|
| Обычный 9539 входит в группу 11-байтовых gap-заголовков; варианты 95391–95397 выделены отдельно | `ui.bt.l1.i`, `q`, `s`, `v`; `ui.bt.t2.H0` |
| Имя разбирается до `#`; профиль обычного устройства — `9539` | `ui.bt.t2.n0`, `ui.bt.l1` |
| Сервис FFF0, запись FFF1, уведомления FFF4, CCCD 2902 | `ui.bt.VsonPtBLE.H`, настройка уведомлений |
| Состояние `01`: ширина мм и точки LE16, состояние, четыре флага ошибок | `ui.bt.t2.h0` |
| `B2` сообщает байт прошивки; отображение как V + hex | `ui.bt.t2.i0`, `ui.main.about.PrinterOtaActivity` |
| `02`: число строк, смещение 0, Q=0, тип ленты, плотность; для gap дополнительно длина, зазор ×10, одна копия | `ui.bt.t2.H0` |
| `03`: номер первой строки LE16, число строк, монохромный растр | `ui.bt.t2.j1`, `util.t` |
| A5 — ответ заголовка; A7/A8 — пауза и продолжение | `ui.bt.t2.i0`, `s0` |
| Для обычного WP9539 непрерывная лента получает ещё 4 мм пустых строк | `ui.bt.l1.o/q`, `ui.bt.t2.j1` |

Дополнительную команду часов BF, настройки питания и обновление прошивки
приложение не отправляет. Разрешены только запросы 01/B2 и команды задания
04/02/03. Изменение часов не является условием печати в просмотренной ветке.

## Ограничения

V31 подтверждена снимком экрана пользователя; это не аппаратное испытание
нашего драйвера. Имя `9539#…` выведено из логики iLabel, а не из захвата
рекламы конкретного принтера. Ширина 12 мм / 96 точек является допустимым
режимом этого профиля и проверяется по ответу 01; другая головка блокирует
печать. Размер рулона не сообщён пользователем и задаётся вручную.

Приложение ожидает свежий idle без ошибок перед заданием и после всех строк.
Пустой буфер в ответе A5, неподтверждённое возобновление A4, ошибки,
тайм-аут и обрыв не считаются успехом. Неизвестный результат хранится
после перезапуска, повтор допускается только вручную после проверки этикетки.

Проверены 19 JVM-наборов, 38 проверок D110, по 33 сценария VSON для каждого
профиля, три UI-профиля с имитацией Bluetooth и обе Android-сборки.
Тесты используют синтетические идентификаторы. Реальная Android BLE-связь,
положение и качество отпечатка пока не проверены.
