# Планы помещений · 0.5.28

Автор: [owlet](https://github.com/owlet12).

## Расстановка в Windows-мосте

1. Откройте свой `.s3project` и нажмите **«Планы…»**. Выберите этаж в верхнем списке либо добавьте PNG/JPEG.
2. Найдите устройство в списке слева. Поиск учитывает описание, наименование, тип, адрес и зону. Есть фильтры по типу и «Только без отметки на этом плане».
3. Выберите строку → **«Разместить выбранное устройство»** → нажмите нужное место на плане. Двойной щелчок по неразмещённому устройству также включает размещение.
4. Отметку можно перетащить мышью. Двойной щелчок по размещённому устройству в списке увеличивает план около него. Для удаления выберите отметку → **«Убрать отметку»**. Само устройство остаётся в проекте.
5. **«Отменить последнее изменение»** возвращает предыдущую расстановку или добавленный/удалённый план; хранится до 50 действий текущего сеанса редактора.
6. Нажмите **«Сохранить планы»**. Закрытие без сохранения не меняет проект и требует подтверждения при наличии правок.

Колесо мыши меняет масштаб около указателя, **−/+** — около центра, **«Весь план»** возвращает общий вид. Пустую область можно перетаскивать; средняя кнопка мыши также перемещает план. Масштаб 100–800%. **Esc** отменяет размещение или незавершённое перетаскивание. Для временного скрытия подписей снимите «Подписи».

В списке и возле отметок используется описание, если оно заполнено, иначе наименование. Оранжевый ободок выделяет выбранную отметку, остальные синие. Цвет в Windows-редакторе обозначает выбор, а не состояние пожарной системы. Одно устройство можно разместить на нескольких планах; на одном плане оно имеет одну отметку.

## Перенос в APK

Обновите **мост и APK до 0.5.28**. После сохранения расстановки в мосте нажмите в APK **«Проект и связь» → «Загрузить проект из Windows»** либо дождитесь включённого автообновления. Альтернатива: Windows → **«Сохранить копию»** → передать `.s3project` → APK **«Открыть файл проекта»**, сохранив перенос планов в предпросмотре импорта.

Планы вместе с изображениями и координатами входят в переносимый проект. Если план не изменялся на телефоне после последней загрузки, APK принимает новую расстановку из Windows, в том числе после перезапуска приложения. Если один план изменили с обеих сторон, APK оставляет местный вариант целиком и показывает сообщение; остальные планы обновляются независимо. Изменения не объединяются по отдельным точкам.

Для выбора Windows-варианта при конфликте сначала экспортируйте местный проект, затем удалите соответствующий план на телефоне и снова загрузите проект из моста. При первом переходе с 0.5.27 после очистки загруженного проекта история принятой версии может отсутствовать: отличающаяся местная расстановка также сохраняется с сообщением. С последующих загрузок 0.5.28 версия учитывается автоматически.

Удаление целого плана в Windows не удаляет уже загруженную копию на телефоне: её нужно удалить отдельно через меню планов APK. Обратный перенос: APK → **«Передать в Windows»** → открыть экспортированный файл в мосте.

## План в карточке устройства APK

Под «Печать описания» нажмите **«Открыть план»**. Если отметка одна, откроется нужный план с выделением устройства; при нескольких планах появится выбор. Если отметки нет, можно выбрать план и указать место. Несохранённые поля карточки остаются при возврате.

Два пальца — масштаб, один — перемещение. Есть −/+, двойное нажатие и «Весь план». Размещение включается отдельно; обычное перемещение изображения отметок не создаёт. Цвета в APK относятся к регистрации, а не к текущему состоянию пожарной системы.

## Сохранение и ограничения

Изменяется `.s3project`; исходный BFX, параметры регистрации и оборудование не затрагиваются. Во время активной регистрации или при изменении проекта другим действием сохранение блокируется: завершите операцию и откройте редактор заново. Сначала сохраняется файл, только затем обновляется проект, выдаваемый телефону.

До 8 планов, PNG/JPEG. Изображение уменьшается до длинной стороны 1800 пикселей и 800 КБ; очень подробный этаж лучше разделить на части. Исходник Windows — до 32 МБ / 40 Мп. PDF/DWG предварительно преобразуйте в PNG/JPEG. Координаты относительные: масштаб окна не меняет положение отметок.

Проверены сборки Android и Windows, модель координат, сценарии размещения/перетаскивания/отмены/фильтров в тестовом Windows-окне, сохранение и чтение проекта, импорт Windows-данных в Android и сохранение местных правок при конфликте. Тесты используют вымышленные устройства. Передачу между установленным мостом и физическим Android-телефоном ещё нужно проверить; установленное ПО и оборудование не запускались.
