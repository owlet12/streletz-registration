# Проверка метаданных маршрута через Панель-Терминал

Инструмент читает PE-метаданные официального Master 12.4 и SHA-256, перечисленные в `VersionGuard.cs`. Сборки изготовителя не загружаются в CLR, их конструкторы, свойства и команды не выполняются. Проверяются сериализуемые поля сегмента и панели, методы чтения пары/адреса ММПИ, распаковка штатного адаптера и точный readonly-токен TunnelDto.

```powershell
dotnet run --project .\probe.csproj -- "C:\Program Files\Streletz-Integral\Streletz-Master" "..\..\master-plugin\VersionGuard.cs"
```

Для запуска инструмента нужен SDK .NET 8. Сам мост и дополнение работают на .NET Framework 4.8. Проверка метаданных не заменяет испытание установленного Master, конкретного BFX и оборудования.
